# 📊 Vendor Performance Analytics Dashboard

An interactive **Vendor Performance Analytics Dashboard** built with Python, Pandas, Plotly, SQLite, and Streamlit.

This project analyzes vendor purchasing and operational data to provide insights into:

- Vendor orders
- Purchase amounts
- Product quantities
- Defects
- Vendor performance
- Purchase contribution
- Defect rates

The project demonstrates an end-to-end data analytics workflow from raw CSV data to an interactive web dashboard.

---

## 🚀 Project Overview

Organizations often work with multiple vendors and large amounts of procurement data.

Analyzing this data manually can make it difficult to identify:

- High-performing vendors
- Vendors generating the most orders
- Vendors receiving the highest purchase amounts
- Vendors with higher defect levels
- Purchasing patterns across vendors

This project transforms raw vendor data into an interactive dashboard that makes these insights easier to explore.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze vendor purchasing activity.
2. Calculate total orders and purchase amounts.
3. Analyze quantities purchased from each vendor.
4. Identify vendor defect levels.
5. Compare vendor performance.
6. Create interactive visualizations.
7. Store vendor data in a SQLite database.
8. Build a web-based analytics dashboard using Streamlit.

---

## 📊 Dashboard Features

### KPI Cards

The dashboard displays key metrics such as:

- Total Orders
- Total Purchase Amount
- Total Quantity
- Total Defects
- Average Purchase per Order

### Vendor Analysis

The dashboard provides:

- Purchase Amount by Vendor
- Orders by Vendor
- Quantity by Vendor
- Defects by Vendor
- Purchase Contribution by Vendor
- Vendor Performance Table

### Interactive Filtering

Users can select vendors from the sidebar to dynamically filter the dashboard.
